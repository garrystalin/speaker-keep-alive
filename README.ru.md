# Speaker Keep-Alive

[English](README.md) | **Русский**

Приложение для Android TV, которое не даёт саундбару (или другой колонке) уйти в режим ожидания.

Многие колонки отключаются, если какое-то время не получают звуковой сигнал. Одни просыпаются сами, когда появляется звук, но первые секунды следующего видео или звука теряются. Другие не просыпаются вовсе: они просто выключаются, и их приходится каждый раз включать вручную. Speaker Keep-Alive раз в несколько минут проигрывает короткий тихий синусоидальный тон. Детектор тишины в колонке видит ненулевой цифровой сигнал и не засыпает, а сам тон при этом почти не слышен.

## Возможности

- Фоновая служба (foreground service) с постоянным уведомлением, которая периодически проигрывает тон.
- Автозапуск после перезагрузки телевизора, если служба была включена.
- Настройка с пульта прямо на экране телевизора. Каждая кнопка переключает значение по кругу:

  | Параметр | Значения | По умолчанию |
  |---|---|---|
  | Интервал | 1, 2, 3, 5, 10, 15, 20, 30 мин | 5 мин |
  | Громкость сигнала (амплитуда) | 1, 2, 5, 10, 20, 40 % | 5 % |
  | Частота | 20, 40, 60, 100, 1000, 15000, 19000 Гц | 40 Гц |
  | Длительность | 1, 2, 3, 5 с | 2 с |

- Кнопка «Проиграть тестовый сигнал» для проверки настроек.
- Нет сети, аналитики и лишних разрешений.

## Установка

Скачайте APK на странице [Releases](../../releases) (или [соберите сами](#сборка)) и установите через `adb`:

1. На телевизоре включите режим разработчика (Настройки → Об устройстве → несколько раз нажать на «Сборка») и «Отладку по USB» или «Отладку по сети».
2. Подключитесь и установите APK:

   ```sh
   adb connect <IP-адрес-телевизора>:5555
   adb install -r speaker-keep-alive-v1.0.0.apk
   ```

3. Запустите приложение из списка приложений Android TV и нажмите «Запустить».

Приложение один раз нужно запустить вручную. До первого запуска Android не доставляет ему `BOOT_COMPLETED`, и автозапуск после перезагрузки не сработает.

## Сборка

Нужны JDK 17 и Android SDK (compileSdk 35). Если Android Studio не используется, укажите путь к SDK в `local.properties`:

```properties
sdk.dir=/путь/к/Android/Sdk
```

Затем:

```sh
./gradlew assembleRelease
```

APK появится в `app/build/outputs/apk/release/app-release.apk`.

Локальная release-сборка подписывается **debug-ключом** (см. `app/build.gradle.kts`). Она годится для установки через `adb`, но не для публикации в магазинах.

## Выпуск релизов

Пуш тега вида `v1.0.0` запускает [workflow Release](.github/workflows/release.yml): он собирает APK и публикует его как GitHub release.

```sh
git tag v1.0.0
git push origin v1.0.0
```

Тег задаёт `versionName`, номер запуска workflow — `versionCode`. Чтобы подписывать релизы собственным ключом, а не debug-ключом, добавьте секреты репозитория: `RELEASE_KEYSTORE_BASE64` (`base64 -w0 release.jks`), `RELEASE_KEYSTORE_PASSWORD`, `RELEASE_KEY_ALIAS`, `RELEASE_KEY_PASSWORD`. Ключ должен быть одним и тем же во всех релизах, иначе Android не даст обновить старую версию новой. [Workflow CI](.github/workflows/ci.yml) собирает debug-APK и запускает lint при каждом пуше в `main` и в pull request'ах.

## Подбор настроек

Детектору тишины важен сам факт ненулевого сигнала, а не громкость.

- **Колонка всё равно засыпает.** Увеличьте громкость сигнала, длительность или уменьшите интервал.
- **Тон слышно.** Уменьшите громкость сигнала или смените частоту. На низких частотах (20–60 Гц) динамики саундбаров почти ничего не воспроизводят. Частоты 15000 и 19000 Гц лежат на границе слышимости, а значит, неслышны не всем.
- Разные колонки по-разному определяют тишину, поэтому оптимальные значения подбираются экспериментально. Кнопка «Проиграть тестовый сигнал» помогает быстро проверить результат.

## Как это работает

- `MainActivity` — экран настроек, собранный из обычных `Button` без XML-разметки, с управлением D-pad'ом.
- `KeepAliveService` — foreground service (тип `specialUse`). Держит `PARTIAL_WAKE_LOCK`, по таймеру запускает тон в отдельном потоке и перепланирует себя с текущим интервалом.
- `Beeper` — генерирует синус с плавным нарастанием и затуханием (100 мс), чтобы не было щелчков, и проигрывает его через `AudioTrack` в стерео, 48 кГц, 16 бит.
- `Prefs` — настройки в `SharedPreferences` с фиксированными наборами значений.
- `BootReceiver` — запускает службу после загрузки, если она была включена.

Параметры тона читаются при каждом сигнале, поэтому их изменение применяется без перезапуска службы. Для интервала служба перезапускается.

## Требования

- Android 6.0+ (minSdk 23), целевая версия — Android 14 (targetSdk 34).
- Рассчитано на Android TV (Leanback), но запустится и на обычном Android-устройстве.
